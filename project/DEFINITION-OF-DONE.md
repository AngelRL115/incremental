# Definition of Done — G1

- [ ] F1–F6 de `goals/G1.md` completadas con evidencia observable, o diferidas mediante autoridad de producto/humana correspondiente.
- [ ] `npm run build`, `npm test` y `npm run balance` pasan; se conservan las pruebas existentes y se documentan las nuevas.
- [ ] Journey P0 completo funciona en navegador con engine real y storage local real.
- [ ] Offline timestamp/cap, automatización y concurrencia multi-tab no duplican progreso.
- [ ] Import inválido conserva save válido y presenta error recuperable/accionable.
- [ ] Preview/cancel/confirm/reset/prestige y progresión permanente se verifican.
- [ ] Canvas independiente de economía, resize/DPR y cleanup; responsive, reduced motion/effects y estados de carga/vacío/error/success verificados.
- [ ] WCAG 2.2 AA revisado en teclado, foco, contraste, nombres/labels y viewports objetivo; sin bloqueantes.
- [ ] Sin errores de consola en journey, mocks/contadores fake, fórmulas duplicadas, secretos, PII o tracking.
- [ ] Identidad aplicada; pantalla listón y visual QA sin Generic Blocker; assets SVG accesibles y originales cuando correspondan.
- [ ] README/documentos reflejan comandos y límites actualizados.
- [ ] `qa-tester` registra sign-off funcional; Security y a11y dejan evidencia de sus gates T2.
- [ ] `git-specialist` prepara resumen del diff/propuesta de commit antes de Done; no se inicializa Git, no se hace commit ni deploy sin precondiciones y autorización humana.
- [ ] Humano informado con evidencia; sin deploy público en este goal.

Estándar de evidencia: paths/resultados de build, suites, browser y findings por AC; no declarar prueba no ejecutada.
