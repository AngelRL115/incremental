# Roadmap de entrega

## G1 — MVP de navegador (Phase 3)
1. Aplicar identidad visual y construir pantalla listón con estado inicial/Canvas responsive.
2. Integrar ticker y acciones con el engine existente; HUD, compras, unlocks y feedback.
3. Persistencia local versionada, export/import/reset y prevención de offline duplicado.
4. Resumen de offline y confirmación/resultado de prestige.
5. Teclado, responsive, reduced-motion, estados de error y pruebas.
6. Validación de build, Vitest, Playwright y navegador real cuando el entorno lo permita.

Gate: G1 AC y tests en `goals/G1.md`; no avanzar a release público por defecto.

## Siguiente
- Balancear con playtest humano y corregir fricciones medidas.
- Evaluar PWA, hosting público/SEO/legal/seguridad operacional solo después de decisión humana.
- Extender contenido original (árboles, logros, historia) tras validar el loop de base.

Phase 4 no se inicia en este goal.
