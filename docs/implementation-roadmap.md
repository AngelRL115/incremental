# Roadmap de implementación

## Gate 0 — Crear y verificar el proyecto
- Crear Vite + React + TypeScript.
- Configurar lint/format si se acuerda usar ESLint/Prettier.
- Confirmar `npm run dev`, `npm run build` y `npm test`.
- Documentar versiones y comandos.

## Gate 1 — Motor mínimo probado
- Estado inicial.
- Recurso primario.
- Producción pasiva.
- Compra de mejora con coste creciente.
- Funciones puras y pruebas unitarias.
- Formateo inicial de números.

## Gate 2 — Primera experiencia jugable
- UI con contadores y producción por segundo.
- Canvas con partículas procedurales.
- Compras y estados bloqueados.
- Autosave versionado.
- Comprobar build y jugar desde navegador.

## Gate 3 — Progresión
- Recursos y generadores adicionales.
- Requisitos explícitos de desbloqueo.
- Mejoras de producción y calidad de vida.
- Pruebas de costes, límites y desbloqueos.

## Gate 4 — Prestigio
- Fórmula documentada.
- Previsualización de recompensa.
- Resumen de pérdida y conservación.
- Reinicio transaccional.
- Pruebas de conservación y reinicio.

## Gate 5 — Progreso offline y recuperación
- Timestamp de guardado.
- Validación de elapsed time.
- Cap configurable si el diseño lo necesita.
- Resumen de retorno.
- Migraciones, exportación e importación.

## Gate 6 — Balance y QA
- Simulador sin UI.
- Métricas de tiempo hasta objetivos.
- Estrategias de gasto y prestigio.
- Pruebas Playwright del recorrido principal.
- Informe de balance.

## Gate 7 — Pulido y publicación
- Diseño adaptable.
- Accesibilidad y reduced motion.
- Perfil de rendimiento.
- Build estático y prueba en hosting estático.

## Regla de salida de cada gate
No marcar una fase como completa por haber escrito código. Requiere pruebas ejecutadas, build relevante y verificación del comportamiento.
